# Changelog

## 0.1.0

First release prepared for public use.

- Save documents, chats, notes, and existing STTP. Ask the current branch with `recall` and `find`.
- Branches, checkout, and stash.
- Merge and rebase on local history.
- `remote`, `fetch`, `push`, and `sync` against another SurrealDB.
- Install from a GitHub release and check `checksums.txt` before the binary is copied.
